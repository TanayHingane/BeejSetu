# Anti-Slop Design: The Human-Grade UI/UX Engineering Skill

> **Mandate:** Eliminate generic AI design tropes (template clichés, boilerplate styling, floating gradient blobs, raw emojis in UI, cookie-cutter 3-card grids) and engineer distinctive, tactile, accessible, and human-grade interfaces.

---

## 1. Trigger Protocol & Agent Persona

### When to Activate This Skill
Invoke this skill automatically when:
- Designing, scaffolding, or refactoring user interfaces (Web, Landing Pages, Mobile).
- Implementing or adjusting CSS, typography, color palettes, or layout grids.
- Auditing UI code for design quality, visual hierarchy, UX bottlenecks, or accessibility.
- The user requests: *"make it look clean"*, *"fix the design"*, *"de-slop this app"*, *"premium feel"*, or *"improve UI/UX"*.

### Autonomous Agent Mindset
1. **Act Directly on Code:** Write concrete CSS variables, semantic HTML, DOM structures, and clean styles.
2. **Preserve Interactive Logic ("Do No Harm"):** Never discard form state, data handlers, validation logic, step transitions, cart drawers, or accessibility hooks during visual refactoring.
3. **Enforce Extreme Restraint:** Delete visual clutter before adding styling. If an element does not deliver immediate user utility, remove it.

## 2. The Anti-Slop Banned Matrix (Strictly Prohibited AI Tropes)

Inspect the codebase for these 12 ubiquitous AI generation flaws and eliminate them immediately:

| AI Slop Anti-Pattern | Manifestation in Vibe-Coded UI | Mandatory Production Replacement |
| :--- | :--- | :--- |
| **The "AI Dark/Neon Mode" Blob** | `radial-gradient` from indigo-600, purple-900, or neon green blurred behind cards or corners. | Deep, deliberate monochrome/botanical surfaces (`#0E2A1D`, `#163827`, `#18181b`) with subtle 1px hairline borders (`rgba(0,0,0,0.08)` or `rgba(255,255,255,0.08)`). |
| **Monotonous SaaS Greens / Slates** | Generic `bg-green-600 text-green-400` or `bg-slate-900` cookie-cutter templates. | Curated semantic tokens with distinct brand personality (e.g., Deep Forest Green, Warm Khadi Parchment, Terracotta Earth, Seed Ochre). |
| **Cookie-Cutter 3-Card Grid** | Three identical rectangular cards with glowing borders on hover. | Dynamic, content-driven layouts: asymmetric editorial grids, staggered narrative steps, or sequential workflow rows. |
| **Raw Emojis as UI Icons** | Plastering raw emojis (`🌱`, `🍎`, `🪴`, `🚀`, `🔥`, `💡`, `📦`) inside buttons, cards, and headings. | Crisp, single-weight vector SVG icons with unified 1.75px stroke widths and consistent viewBoxes. |
| **Fabricated Vanity Stats** | Meaningless filler cards: `"+99.9% Viability"`, `"10x Faster"`, `"50k+ Users"` with no real source. | Real domain facts grounded in the Pune & Western Ghats pilot. Zero vanity metrics. |
| **Screaming Eyebrow Labels** | Tracked-out uppercase labels above every heading: `OVERVIEW`, `FEATURES`, `ABOUT US`. | Clean sentence-case hierarchy, subtle metadata tags, or omit entirely if the heading is self-explanatory. |
| **Single-Word Italic/Color Accents** | Headlines with one arbitrary word italicized or highlighted in glowing gradient text. | Uniform, confident typographic weight. Let the whole statement carry authority. |
| **Redundant Metric Duplication** | Repeating total numbers in header, hero, and multiple individual cards. | Single source of metric truth. One primary summary per viewport. |
| **Floating Decorative Cards** | Random angled cards floating in the hero with fake charts or graphs. | Contextual, grounded preview of the real experience or clean typography with breathing room. |
| **Missing Interactive States** | Buttons with only hover effects, lacking `:focus-visible`, `:active`, loading, and disabled states. | Complete interactive feedback system on all interactive primitives. |
| **Broken Placeholders & Links** | `via.placeholder.com`, broken Unsplash URLs, or blurry stock photos. | High-fidelity inline SVGs, semantic CSS abstract shapes, or verified local assets. |
| **Generic Centered Hero** | Centered small pill badge + 3-line headline + generic 2 buttons + random screenshot below. | Intentional editorial composition tailored to the specific product identity. |

## 3. Core UX Axioms

### Axiom 1: The "1-to-3" Rule (Triangle of Focus)
Every meaningful screen zone or container must follow the 1-to-3 scaling law:
- **1 Primary Element / Action** (The unambiguous focal anchor).
- **Max 3 Secondary Logics** (Supporting metadata, controls, or links).
- *Violation Check:* If a card or toolbar contains 5+ equal-weight buttons or badges, group or prioritize them.

### Axiom 2: The 85% Statistical Prioritization Law
Design interfaces for real usage frequency, not theoretical edge cases:
- Identify the **Primary Scenario** used by 85% of users (e.g., "Donate Cleaned Seeds from Kitchen Fruit" or "Order Indigenous Heirloom Seeds"). Make this action prominent, instantaneous, and zero-click accessible.

### Axiom 3: The Strict Ban on Duplication
- Exactly **one** primary brand mark in the header.
- Exactly **one** primary CTA per viewport zone.
- Zero duplicate headers or redundant banner announcements.

## 4. Typographic Mastery & Spatial Discipline

1. **Pairing Rule:** Use maximum 2 font families:
   - *Display / Headings:* Distinct character (e.g., `Outfit`, `Playfair Display`, `Plus Jakarta Sans`).
   - *Body / UI:* Clean, high-legibility sans-serif (e.g., `Plus Jakarta Sans`, `Inter`, system font stack).
2. **Line Length & Leading:**
   - Body paragraphs constrained to `60ch` - `75ch` maximum for optimal human reading speed.
   - Generous line-height (`1.6` to `1.75`) for editorial warmth.
3. **Spatial Grid:**
   - Strict 4px/8px modular rhythm (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`).
   - Generous section padding (`80px` to `120px` desktop, `48px` to `64px` mobile) to let content breathe.
